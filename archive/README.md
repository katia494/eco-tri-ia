# Expérimentations archivées

Ces fichiers documentent les premières pistes du projet mais ne font pas partie
du pipeline final :

- `models/model_experimental_random_forest.pkl` : ancien modèle tabulaire ;
- `notebooks/entrainement_random_forest_synthetique.ipynb` : expérimentation sur
  des variables synthétiques qui ne correspondent pas à l'entrée image de l'application.

Le modèle livré et utilisé par l'API est `backend/models/best.pt` (YOLOv8n-cls).
